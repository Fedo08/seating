# seating
正式宴會主桌座位排定系統
簡易使用說明
單一 HTML 檔　•　開啟即可用　•　v12
1. 這是什麼
一份用瀏覽器開啟的網頁工具，專門安排「一個圓桌主桌」的座位。不需安裝。
•	建議使用 Chrome、Edge 或 Safari
•	適用正式晚宴、頒獎、貴賓桌等場合
2. 如何開啟
•	雙擊 HTML 檔，或把檔案拖進瀏覽器視窗
•	開啟後左側是賓客名冊，右側是圓桌畫布
3. 畫面說明
•	上方：晚宴名稱、日期、時間、地點、功能按鈕
•	左側：賓客列表（可搜尋、篩選、多選）
•	右側：圓桌與各席名牌（可拖曳整桌）
4. 操作步驟
① 填寫晚宴資料
•	直接在上方修改名稱、日期、時間、地點
•	這些資料會出現在列印頁抬頭
② 設定主桌
•	點「設定主桌人數」或圓桌中心的「人數」
•	可改桌名、席位數（4～24）、第1席位置、順／逆時針
③ 建立賓客名冊
•	單筆新增：填姓名、單位／身份、顏色、備註
•	批量匯入：從 Excel 複製「姓名＋單位＋備註」貼上
④ 安排座位
•	手動：從左側拖曳賓客到圓桌席位
•	智能排位：點上方按鈕，依身份優先自動安排未入座者
•	多選：Ctrl（Mac 用 Cmd）點選多位，一次拖到目標席
•	請起：點名牌右上角 ✕，或拖回左側，或選取後按 Delete
⑤ 列印與備份
•	列印：點「列印配置」→ 選擇是否顯示空席 → 確認列印
•	第1頁＝平面座位圖　／　第2頁＝席次名冊
•	備份：點「儲存備份」下載 JSON；之後可用「載入備份」還原
5. 快捷鍵
•	Ctrl + S（Mac：Cmd + S）→ 儲存備份
•	Delete → 將選取的賓客請起
•	Esc → 關閉彈窗
•	Ctrl + 點擊 → 多選
•	Shift + 點擊 → 範圍選取
6. 列印提醒
•	紙張選 A4 直式
•	請勾選「背景圖形／背景顏色」，才印得出色標
•	可選擇不顯示空席，畫面更簡潔
7. 注意事項
•	目前只支援單一圓桌主桌
•	重要排位請務必「儲存備份」，避免換電腦後資料消失
•	字太小可用瀏覽器 Ctrl + 加號放大
